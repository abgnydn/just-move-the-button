# Just Move the Button
An interactive comic about the invisible work behind a "five-minute" software change. Play as the developer or the ticket writer, guess what breaks, watch it break, learn where to look.

- Dev: serve the folder (`python3 -m http.server`) and open index.html
- Build one shareable file: `python3 tools/build.py` → dist/index.html
- Extend: read docs/SKILL.md first, then docs/DESIGN.md

Assets: heroes generated in Gemini and cut with tools/cut_sheets.py. Free to copy, translate, remix.
